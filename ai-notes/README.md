# AIの作業記録

AIによる調査・作業計画・引継ぎの置き場です。Gitで管理し、確定仕様や作業指示の正本とは区別します。

## 現在の記録先

再開時はMVP実装計画の「現在の次作業」から確認します。作業計画と未確定候補はこのディレクトリで管理し、確定仕様・判断は下記の正本を参照します。内容はここへ複製しません。

| 記録 | 用途 |
| --- | --- |
| [MVP実装計画](mvp-implementation-plan.md) | 作業単位、着手前の質問、「現在の次作業」の引継ぎ |
| [可読性リファクタリング実行計画](readability-refactoring-plan.md) | 製品コードと全テストの全行精査、修正の判断基準と完了条件 |
| [判断記録](../docs/decisions.md) | 確定した判断と理由 |
| [開発候補](development-candidates.md) | 未確定事項・検討候補 |
| [ロードマップ](../docs/roadmap.md) | 製品の開発方針 |

## 整理の手順

追加・更新・再開・中断時は[AGENTS.mdの「記録の整理と維持」](../AGENTS.md#記録の整理と維持)に従います。移設した場合はこの一覧と参照元を更新します。

利用・開発文書や長く残す設計判断は `docs/` 等の既存資料、指示は `docs/ai-instructions/` に置きます。一時実験・生成物・生ログは既存の無視対象へ置き、この場所に秘密情報や端末固有の絶対パスを残しません。
