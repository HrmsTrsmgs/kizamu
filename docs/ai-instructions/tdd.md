# TDDの入口

通常は共通Skill `tdd-workflow`、未導入時は [進行手順](tdd-context/run.md) を使う。固有の制約と記録先は [AGENTS.md](../../AGENTS.md) に従う。

進行役は選んだ進行手順だけ、工程担当は同じ側の [工程共通](tdd-context/common.md) と担当工程だけを読む。共通Skillと参照版を混用しない。レビュー・コミット・段階停止の詳細は進行手順に集約する。
