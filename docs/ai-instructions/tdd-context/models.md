# モデル選択の開始方針

共通 `tdd-workflow/references/models.md`（`codex-workflows e66db1d` 基準、モデル割当は2026-11-04更新）のリポジトリ内参照版。

進行役だけが必要時に読む。工程名だけでモデルを固定せず、利用環境の実在するモデルID・推論設定・指定権限を確認する。この文書は設定済みや性能の保証ではない。

費用や利用枠を未確認のまま断定せず、高額設定はユーザーの承認済み範囲を超えて使用しない。

- Luna系: 契約が明確な通常Green、定型的なテスト展開、局所的な命名・重複整理。
- Terra系: 外部APIとcall siteの設計、共通化の判断、責務・抽象化・依存方向を扱うRefactor。
- Sol系: 問題設定・制約・観測事実が揃い、Terraでは扱い切れない広範囲・多制約の問題で候補とする。「重要」「上流」「原因不明」だけでは選ばない。

情報不足は必要資料の取得で解消する。ユーザーのモデル指定と利用環境の制約を優先し、選択の議論を工程担当へ渡したり、工程中に細かくモデルを交代させたりしない。
